# Un universo para Fernanda

Página de Manuel para Fernanda con la fecha 05/02/2025, cielo animado con parallax, Hello Kitty, galería ampliable de tres fotos y carta en un sobre. Incluye un contador desde el 5 de febrero de 2025 a medianoche de Colombia, deseos con estrellas fugaces y transiciones al desplazarse. Respeta la preferencia de movimiento reducido y pausa el cielo cuando la pestaña está oculta. El mensaje es una propuesta que puedes personalizar en `dist/index.html`.

## GitHub Pages

La entrada pide la fecha en que se conocieron: **05/02/2025**. Acepta día y mes con o sin cero inicial. Todo el contenido permanece oculto hasta acertarla y vuelve a cerrarse al recargar o pulsar «Cerrar universo». Es una puerta interactiva, no una protección de datos: en GitHub Pages los archivos y la fecha pueden inspeccionarse en el código.

Incluye cinco estrellas con mensajes, tarjetas «abre cuando», una sección del primer encuentro y una lista de deseos guardada en `localStorage` de este navegador. El botón «Enviar a Manuel» abre el chat con +52 1 663 330 5059 y el texto exacto del deseo; la persona debe pulsar Enviar en WhatsApp. El enlace utiliza el número de WhatsApp proporcionado; el destinatario aparece al abrir el chat. Los textos de las cartas y tarjetas son propuestas editables en `index.html` y `experience.js`.

1. Sube **todo el contenido de `dist`** a la raíz de tu repositorio: los archivos HTML, CSS y JavaScript y la carpeta `assets`.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main`, carpeta **/(root)** y guarda.

También puedes abrir `dist/index.html` directamente para ver la página. No requiere compilación. Las tipografías de Google Fonts usan fuentes alternativas si no hay conexión.
